# Style reference

Approved pilot (1-000 to 1-029, checked in-game). Match this voice.

## Voices
| Who | Voice |
|---|---|
| Taison (前田) | Blunt, hot-headed, short sentences; "Don't screw with me!", "Whaaat?!". Soft-spoken and clumsy around Chiaki. |
| Chiaki | Gentle, hesitant with Taison ("Maeda-kun..."), but firm when she scolds him. |
| Kazumi | Breezy gossip, teases. Calls Taison Maeda-san. |
| Katsuji, Yoneji | Taison's loyal pals; Maeda-san; casual guy talk. |
| Koheiji | Loud braggart, refers to himself grandly (Koheiji-sama), throws in English "BABY", "BOY". |
| Thugs | Sneering: "Smart boy.", "You listening?! Huh?!" |
| Narration | Plain past tense, third person; long JP narration sentences may be split across several entries: keep the pieces reading in sequence ("He got dragged into...", "...and ended up..."). |
