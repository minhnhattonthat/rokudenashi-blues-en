Rokudenashi Blues: Taiketsu! Tokyo Shitennou - English Translation v{VERSION}
==========================================================================

Unofficial fan translation of the 1994 Bandai Super Famicom game based on Masanori Morita's
manga "Rokudenashi Blues". Not affiliated with Bandai, Shueisha or Masanori Morita.
No ROMs are distributed; apply the patch to your own dump.

APPLYING
--------
Patch format: BPS. Use Floating IPS (Flips), Beat, or an online patcher (e.g. RomPatcher.js).

Base ROM (No-Intro: Rokudenashi Blues - Taiketsu! Tokyo Shitennou (Japan).sfc, 1,572,864 bytes, no header):
  {BASE}
Patched ROM (2,097,152 bytes):
  {PATCHED}

If your file is 1,573,376 bytes it has a 512-byte copier header: remove it first.
Start the patched game from a cold boot; savestates made with the Japanese ROM won't carry the new text.

WHAT'S TRANSLATED
-----------------
- All story dialogue and narration (variable-width font, word-wrapped by the game at runtime)
- Title menu, options screen, command labels, intro shouts, staff credits
- Graphics: boot copyright screen, title logo (subtitle: "Showdown! Tokyo's Four Kings"), fight banners,
  RAGE gauge, ending logo, story sound effects

Names follow the manga in Japanese order (Maeda Taison) with honorifics kept (Maeda-kun, Chiaki-chan).

KNOWN ISSUES
------------
- The anti-copier warning screen (only shown on copier hardware) is untranslated.

Tested in Mesen 2.
